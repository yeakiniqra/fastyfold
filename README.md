# fastyfold

A modern admin panel for FastAPI, inspired by [Django Unfold](https://github.com/unfoldadmin/django-unfold).

> Status: early design. Not ready for use yet.

## Goals

- Mount at `/admin` with one line, `pip install` only (no Node build for users)
- Forms generated from your existing Pydantic models
- SQLAlchemy 2.0 async and SQLModel
- Built-in login, per-model permissions and audit log
- Unfold-style UI: Tailwind, HTMX, Alpine.js, dark mode, themeable colours
